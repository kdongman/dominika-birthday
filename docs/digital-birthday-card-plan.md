# 디지털 생일 포토카드 기획

작성일: 2026-10-31 · 상태: 감상 프로토타입 및 로컬 사진·음악 설정 구현

## 1. 제품의 한 문장

사진 한 장과 편지, 좋아하는 노래를 담아 보내고, 마지막에는 소원을 빌며 초를 끄는 디지털 생일카드.

보내는 사람은 짧은 시간 안에 자신의 취향을 담은 선물을 만든다. 받는 사람은 휴대폰에서 링크를 열어 카드를 감상하고 작은 생일 의식을 경험한다. 인쇄·배송 없이 디지털로 완결한다.

### 핵심 결정

- 기존 포토카드 컬렉션과 별도의 ‘생일카드 만들기’ 진입점과 제작 흐름을 둔다.
- 기본 단위는 앞뒤가 있는 카드 한 장과 마지막 소원 장면이다. 8장 컬렉션 조건을 적용하지 않는다.
- 사진·편지·노래가 중심이고 장식은 이들을 돋보이게 한다.
- 받는 사람은 설치나 로그인 없이 링크로 감상한다.
- 촛불 끄기는 편지를 읽은 다음, 경험의 마지막에 둔다.
- 첫 구현은 도미니카 카드의 감상 흐름부터 완성하고 제작기로 확장한다.

## 2. 받는 사람의 경험

**링크 열기 → 카드 앞면 바로 보기 → 편지 읽기·음악 듣기 → 마지막 소원 → 다시 감상**

### 장면 A. 도착한 선물

- 중앙에 세로형 포토카드의 앞면을 보여준다. 사진이 주인공이 된다.
- 이름과 생일 날짜, 작은 보내는 사람 표기를 배치한다.
- 상단 문구: “너를 위한 카드가 도착했어.”
- 링크를 열면 카드 앞면이 바로 보인다. 별도 시작 화면이나 `카드 열기` 버튼은 두지 않는다.
- 음악 파일이 설정되어 있다면 페이지 진입 시 재생을 시도한다. 브라우저가 소리 자동 재생을 막으면 카드 아래 플레이어에서 한 번 눌러 재생할 수 있게 안내한다.
- 링크 미리보기에는 기본 선물 이미지와 제목만 사용한다. 개인 사진이나 편지 내용은 기본으로 노출하지 않는다.

### 장면 B. 사진, 편지, 음악

- 카드를 열면 짧은 회전 전환으로 뒷면의 편지를 보여준다.
- `사진 보기`와 `편지 보기`로 앞뒤를 자유롭게 오간다. 긴 편지는 정상적인 세로 스크롤로 읽는다.
- 편지는 인사말, 본문, 서명으로 구성한다. 강제 타이핑 효과 없이 읽을 수 있게 한다.
- 음악이 있다면 편지 아래 또는 카드 옆에 플레이어와 노래에 대한 한마디를 배치한다.
- 버튼 문구: `마지막으로 하나 더`
- 버튼은 편지를 다 읽은 다음 자연스럽게 발견하도록 본문 뒤에 둔다. 시간 제한이나 강제 대기는 없다.

### 장면 C. 마지막 소원

- 배경이 어두워지고 케이크와 켜진 초가 등장한다.
- 도입: “잠깐, 아직 하나 남았어.”
- 제목: “마지막으로, 소원 하나 빌어봐.”
- 안내: “마음속으로 소원을 빌고, 초를 눌러 꺼줘.”
- 나이가 입력되어 있으면 숫자 초, 입력하지 않으면 일반 초 한 개를 쓴다.
- 초를 누르면 불꽃이 꺼지고 짧은 연기와 별이 올라온다. 연출은 약 1~2초 안에 마무리한다.
- 완료: “소원 접수 완료. 무슨 소원인지는 비밀로 해 🤫”
- 후속 문구: “오늘 하루가 네 마음에 오래 남기를.”
- 버튼: `카드 다시 보기` · 보조 버튼: `소원 한 번 더 빌기`
- 소원을 입력하거나 수집하지 않는다. 마이크 권한 없이 터치로 진행한다.
- 반복 탭해도 효과와 완료 처리가 중복되지 않게 한다.

### 감정의 흐름

궁금함 → 사진을 보며 반가움 → 편지를 읽으며 집중 → 마지막 작은 놀라움 → 따뜻하고 장난스러운 마무리.

## 3. 만드는 사람의 경험

데스크톱에서는 왼쪽 편집 도구와 오른쪽 실시간 미리보기, 모바일에서는 편집 화면과 전체 미리보기를 전환한다. 단계마다 저장 상태를 보여준다.

| 단계 | 입력·선택 | 기본값과 제약 |
| --- | --- | --- |
| 1. 기본 정보 | 받는 사람, 보내는 사람, 생일, 나이 | 이름 필수, 생일·나이 선택. 나이는 표시 여부 선택 |
| 2. 사진과 스타일 | 대표 사진 한 장, 자르기, 템플릿, 배경색, 프레임 | 사진 없이 사용할 기본 일러스트 제공. 얼굴을 임의로 잘라내지 않도록 직접 위치 조정 |
| 3. 편지 | 제목, 본문, 서명 | 본문 권장 100~500자, 최대 2,000자. 공백뿐인 편지는 발행 불가 |
| 4. 노래 | 음악 없이 / 로컬 오디오 파일 / Spotify 곡·팟캐스트 링크 | 음악은 선택. 파일을 미리 듣고, Spotify는 임베드 플레이어로 재생 |
| 5. 마지막 소원 | 숫자 초 또는 일반 초, 완료 문구 | 소원 장면 기본 포함. 문구는 짧게 수정 가능 |
| 6. 확인과 보내기 | 수신자 화면 전체 미리보기, 링크 만들기 | 발행 완료 후에만 실제 공유 링크 제공 |

주요 버튼은 `다음` → `전체 미리보기` → `링크 만들기`로 이어진다. 공유 전 사진과 편지를 다시 확인할 수 있다. 공유 취소 또는 링크 폐기도 제공한다.

### 꾸미기의 범위

- 템플릿별로 어울리는 배경색과 글꼴 조합을 제공한다.
- 프레임 3종, 글꼴 조합 3종, 선택형 스티커 소량으로 시작한다.
- 스티커는 정해진 위치에 최대 3개까지 배치한다. 편지나 얼굴을 덮지 않도록 한다.
- 자유 캔버스, 임의 레이어, 스티커 업로드, 정교한 사진 편집은 후속 범위다.
- 템플릿 변경 시 사진·편지·음악 입력 내용은 유지한다.

## 4. 시각 디자인

카드 바깥은 여백을 넉넉하게 두고, 카드 안의 사진과 글에 시선이 모이도록 한다. 조작 버튼과 장식은 구별한다. 모든 템플릿의 정보 구조와 버튼 위치는 일관되게 유지한다.

| 템플릿 | 분위기 | 구성 |
| --- | --- | --- |
| Midnight Wish | 도미니카 샘플의 첫 스타일 | 잉크색 배경, 흰 카드, 파란 포인트, 적은 수의 별 |
| Paper Letter | 차분한 편지 | 크림색 종이, 절제된 프레임, 잉크색 글자 |
| Birthday Pop | 가볍고 즐거운 축하 | 밝은 단색, 선명한 포인트, 작은 스티커 |

첫 프로토타입은 Midnight Wish 한 가지를 완성한다. 제작기 첫 공개 시 나머지 두 가지를 추가한다. 카드 뒤집기와 초 끄기에 움직임을 집중하고, 편지를 읽는 동안에는 장식이 주의를 빼앗지 않게 한다.

## 5. 음악 설계

### 현재 프로토타입: 로컬 파일 또는 Spotify 임베드

- 제작자가 MP3, M4A, WAV, OGG 파일(최대 20MB)을 선택하고 미리 들을 수 있다.
- 로컬 파일은 카드 페이지 진입 시 재생을 시도한다. 브라우저 정책상 소리 자동 재생이 차단될 수 있으므로, 플레이어의 재생 버튼으로 바로 시작하는 대체 경로를 제공한다.
- Spotify 곡과 팟캐스트 링크는 공식 임베드 플레이어로 재생한다. 팟캐스트 에피소드에는 초 단위 시작 지점을 지정할 수 있다.
- Spotify 공식 임베드의 사용자 지정 시작 지점은 팟캐스트 에피소드용이다. 곡 임베드에는 원하는 구간부터 시작하는 지원 기능이 없으므로 곡 일부를 지정하려면 로컬 오디오 파일을 쓴다.
- 앞면/편지/소원 화면을 이동해도 같은 플레이어를 유지한다.
- 로컬 파일은 현재 브라우저 미리보기에만 적용되고 새로고침하면 초기화된다. 백엔드와 발행 링크가 없어 로컬 음원이 다른 기기의 수신자에게 전달되지는 않는다.
- 실제 공유를 구현할 때는 오디오 파일 업로드·저장, 크기 제한, 삭제 정책을 카드 발행 흐름에 연결해야 한다.
- 소원을 빌기 위해 음악을 반드시 켤 필요는 없다.

YouTube 연결은 후속 검토로 둔다. 추가한다면 최소 크기 요건을 지키는 보이는 영상 플레이어로 제공한다. 숨겨진 배경음악 플레이어로 기획하지 않는다.

## 6. 저장과 공유

현재 도미니카 앱은 서버 없는 React/Vite 앱이다. 제작·저장·공유 기능은 아직 구현되어 있지 않으며, 아래 내용은 추가 개발 범위다.

- 편집 중인 카드는 초안으로 저장하고 제작자만 접근한다.
- 제작기 초기 체험은 샘플로 가능하게 하고, 영구 저장·발행 시 제작자 계정을 연결하는 방식을 제안한다.
- 발행 시 카드 데이터와 사진이 서버에 저장된 뒤 실제 감상 링크를 발급한다. 로컬 미리보기 URL을 공유 링크로 표시하지 않는다.
- 받는 사람은 계정 없이 볼 수 있다. 링크를 가진 사람은 전달받아 열 수 있다는 점을 발행 화면에 짧게 설명한다.
- 생일카드용 ‘링크로 공유’ 상태를 별도로 정의한다. 기존 포토카드의 Private/Public 규칙을 조용히 변경하지 않는다.
- 검색이나 공개 갤러리에 자동 등록하지 않는다. 검색 제외 처리는 접근 통제를 대신하지 않는다.
- 발행된 버전과 편집 중 초안을 구분한다. 수정한 내용은 `공유 카드 업데이트`를 눌러 반영한다.
- 제작자가 링크를 폐기하면 해당 링크로 더 이상 카드와 사진을 조회할 수 없어야 한다.
- 공유 사진은 감상용 이미지로 제공하고 원본 파일을 별도로 노출하지 않는다. 링크 폐기 시에도 계속 접근 가능한 공개 원본 주소를 사용하지 않는다.
- 첫 버전에는 수신자 활동 추적이나 열람 알림을 넣지 않는다.

### 데이터 구성 초안

| 영역 | 주요 값 |
| --- | --- |
| 카드 | ID, 제작자 ID, 초안/발행 상태, 언어, 생성·수정 시각 |
| 수신 정보 | 받는 사람, 보내는 사람, 생일(선택), 나이(선택) |
| 디자인 | 템플릿 ID, 사진 참조, 자르기 위치, 팔레트, 프레임, 스티커 |
| 편지 | 제목, 본문, 서명 |
| 음악 | 없음/오디오 파일/Spotify URI, 형식, 시작 지점, 곡 이름, 한마디 |
| 소원 | 초 스타일, 안내 문구, 완료 문구 |
| 공유 | 추측하기 어려운 토큰, 발행 버전, 발행·폐기 시각 |

## 7. 첫 버전의 범위

### 포함

- 별도 생일카드 제작 흐름과 앞뒤 한 장 구성
- 대표 사진 한 장 또는 기본 일러스트
- 편지와 제한된 꾸미기
- 선택형 오디오 파일 또는 Spotify 곡·팟캐스트와 재생 컨트롤
- 전체 수신 경험 미리보기
- 모바일 감상, 마지막 터치 촛불 끄기, 다시 보기
- 서버 저장, 링크 발행·업데이트·폐기
- 음악 없음·사진 없음·긴 편지·재생 실패 상태

### 후속

공유 카드용 음원 파일 저장, 마이크로 실제 불기, 여러 장의 사진, 공동 편지 작성, 예약 전달, 결제, 공개 탐색, 컬렉션 보관함 연동, 영상 내보내기.

## 8. 구현 순서

### 1단계 — 도미니카 감상 프로토타입

기존 앱의 순서를 ‘인사 → 편지 → 마지막 소원’으로 바꾸고 포토카드 앞뒤 표현을 추가한다. 기존 편지 내용을 유지한다. 터치로 초 끄기와 다시 보기를 연결한다. 음악은 사용자가 고른 로컬 오디오 파일로 연결한다. 사진 미제공 시 기본 일러스트를 사용한다.

완료 기준: 한 사람에게 보내는 카드의 전체 감상 흐름이 완성되어 제작기 UI 없이도 경험을 판단할 수 있다.

### 2단계 — 제작기

카드 내용을 데이터로 분리하고 단계별 입력, 사진 자르기, 꾸미기, 음악 선택, 실시간 미리보기를 만든다. 템플릿 3종을 제공한다. 이 단계의 임시 저장과 미리보기는 기기 내 기능이며 실제 공유와 구분한다.

완료 기준: 샘플을 새 생일카드로 바꾸고, 자신의 입력이 전체 감상 화면에 반영되는 것을 볼 수 있다.

### 3단계 — 저장과 실제 전달

제작자 인증, 이미지 저장, 카드 발행 버전, 공유 링크 조회·폐기를 구현한다. 기존 포토카드와 연결할 경우 생일카드 전용 데이터 및 공유 정책을 문서화한다.

완료 기준: 제작자가 보낸 링크를 다른 기기에서 로그인 없이 열 수 있고, 폐기 후에는 조회되지 않는다.

## 9. 구현 시 확인할 기준

- 받는 사람은 이름·편지·사진을 작은 휴대폰 화면에서도 읽고 볼 수 있다.
- 화면 폭에 따른 가로 넘침이 없고, 긴 편지는 잘리지 않는다.
- 음악을 재생하지 않거나 재생에 실패해도 카드와 소원 흐름을 끝낼 수 있다.
- 앞뒤 전환과 소원 화면 이동이 음악 플레이어를 불필요하게 초기화하지 않는다.
- 초 끄기 버튼은 키보드와 스크린리더로도 조작할 수 있다.
- 움직임 줄이기 설정에서는 카드 회전과 날아가는 별을 줄이고 상태 변화는 분명하게 표시한다.
- 소원 완료 문구는 보조기술에도 전달한다. 장식 효과가 조작을 막지 않는다.
- 사진·음악 업로드 실패가 기존 입력을 지우지 않는다.
- 초안·발행본·폐기된 링크의 접근 범위가 각각 지켜진다.

## 10. 제작에 필요한 실제 콘텐츠

도미니카 샘플의 편지는 기존 내용을 사용한다. 대표 사진과 음악은 아직 선택되지 않았다. 두 항목이 없어도 기본 일러스트와 음악 없는 상태로 프로토타입 제작을 진행할 수 있다. 수신자 문구는 기존 샘플처럼 영어로, 제작기 안내는 한국어로 시작하는 것을 제안한다.

현재 코드에는 도미니카 감상 흐름과 사진·오디오 파일·Spotify 링크를 바꾸는 로컬 편집 창이 반영되어 있다. 대표 사진과 노래는 아직 선택되지 않아 기본 일러스트와 음악 없는 상태를 사용한다. 선택한 사진과 로컬 음원은 현재 브라우저 미리보기에만 적용되며, 제작기 초안 저장·서버 저장·실제 공유 링크 발행·폐기는 후속 단계다.
